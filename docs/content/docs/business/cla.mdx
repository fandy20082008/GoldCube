# 贡献与上游 CLA

仓库保留的 `CLA.md` 是旧上游的 Contributor License Agreement，见[旧 AGPL 基线原文](https://github.com/csyqlz/VOZEB-PRO/blob/04b32d31ca00272e3866c85e9a8329036c63af72/CLA.md)。其中的项目方、联系邮箱和再授权条款是上游历史内容，不表示 GoldCube 已取得上游独立商业授权，也不能直接作为 GoldCube 接受新贡献的授权依据。

GoldCube 的新贡献在贡献条款和接收责任人经专项审核确认前暂缓接收；不要仅凭仓库中的旧协议推定已与二开项目达成贡献授权。

## 贡献前请确认

- 你有权提交相关代码、文档或素材。
- 第三方内容已明确标注来源，并且授权方式与本项目兼容。
- 提交内容适用于拟议的开源发布方式；涉及另行商业授权时，须有明确权利依据。
- 安全漏洞不要通过公开 Issue 直接披露细节，请按[漏洞提交](/docs/support/security)流程处理。
