# 第三方 GitHub 提示词仓库

首发源码不内置第三方聚合提示词库，也不在读取公共列表时自动导入种子。新安装的公共库为空；管理员可以自行创建公共条目，用户可以创建、导入和管理个人提示词。

导入或分享第三方提示词、封面时，应自行核对原始作者、许可、肖像、商标、隐私及相关权利。聚合仓库的统一许可声明不能代替每项原始内容的授权。通用图片上传、预览仍可使用，专用于旧聚合库封面的远程图片代理已停用。

升级已有安装时，历史公共种子不会因读取页面而自动删除或重建。管理员应先盘点、备份并审查历史数据，再在维护窗口按批准的迁移计划隔离受管公共条目；用户自行创建或复制的个人条目不属于自动迁移范围。
